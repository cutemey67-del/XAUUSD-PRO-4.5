XAUUSD PRO V3.5 LIVE
1. Create a GitHub repository.
2. Upload index.html.
3. GitHub Settings -> Pages -> Deploy from branch -> main -> /root.
4. Open the generated Pages URL on Android.
5. Enter your Twelve Data API key in the app and press Test Connection, then Start Live.

Important: never commit an API key into the repository. The app stores the key in browser localStorage.
The dashboard is analysis-only and does not place trades automatically.
